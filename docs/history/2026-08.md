  - 现象：Hermes（MCP Python SDK，Streamable HTTP 传输）调用工具偶发挂起至 300s tool_timeout（实测 `get_weekly_report` 300.02s 超时）；**同刻 curl 直连 `:8799/mcp` 完全正常**（13.2s 返回）——排查迷惑点
